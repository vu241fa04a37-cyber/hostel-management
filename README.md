# 🏨 Simple Hostel Management System

A simple, clean, and beginner-friendly Hostel Management System website built with **React**, **HTML**, **CSS**, and **JavaScript** (using **Vite** and **Tailwind CSS**).

---

## 📁 Simple Project Structure

```
hostel-mangement/
├── index.html          # HTML entry point (Tailwind CSS & Google Fonts)
├── package.json        # Dependencies (React, Vite, Lucide Icons)
├── vite.config.js      # Vite configuration
└── src/
    ├── main.jsx        # React root renderer
    ├── App.jsx         # Complete, simple Hostel Management App (5 tabs)
    ├── mockData.js     # Simple starter data (rooms, students, fees, complaints)
    └── index.css       # Clean styling
```

---

## 🌟 5 Core Features

1. **📊 Dashboard**: Quick overview cards (Total Rooms, Available Beds, Total Students, Fees Collected, Open Complaints).
2. **🛏️ Rooms**: Add new rooms, view room numbers, types (Single, Double, Triple), monthly rent, and occupancy status.
3. **👨‍🎓 Students**: Register students with name, phone, email, college, and assigned room. Includes automatic bed occupancy tracking.
4. **💳 Fees**: Track student fee bills (Paid vs Pending) with 1-click status toggling and custom invoice creation.
5. **🛠️ Complaints**: Log student maintenance issues and resolve them with a single click.

## 🚀 How to Run

1. Open your terminal in this project folder:
   ```bash
   npm run dev
   ```
2. Open your browser at:
   `http://localhost:3000`
